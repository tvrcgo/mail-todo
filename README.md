# Todo

用你自己的邮箱当待办后端的桌面应用。所有任务都以邮件形式保存在邮箱里。

## 它解决什么问题

待办数据不该被锁在某个云服务里。Todo 把「一条待办」直接映射成「邮箱里的一封邮件」：

| 待办概念 | 邮箱里是什么 |
|---|---|
| 新增一条 | 往列表文件夹里写入一封邮件 |
| 标记完成 | 把邮件标为已读 |
| 设为重要 | 给邮件打上旗标 |
| 默认列表 | 顶部导航的「任务」直接对应**收件箱** |
| 自建列表 | 列表区里的每一项对应一个 `Todo-` 开头的邮箱文件夹 |
| 备注 | 邮件正文 |

因此任务不是被某个 App 加密藏起来的东西，而是你能在任何邮件客户端里看到、改到、搜索到的真实邮件。应用本身不存业务数据，换一台电脑登录同一个邮箱就自动同步。

## 主要特性

- 左侧导航（今天 / 重要 / 任务）+ 自建列表，详情以抽屉形式覆盖任务区
- 新建、编辑、勾选完成、标为重要、删除、跨列表搜索、截止日期、到期提醒
- 列表可新建、重命名、删除，均落到邮箱文件夹上
- 顶部「任务」= 收件箱；列表区 = 自建的 `Todo-` 文件夹，可新建与删除
- 断网可看（只读快照），恢复后自动续传
- 常驻托盘，关闭窗口不退出
- 凭证用系统 DPAPI 加密保存，不落明文

## 部署

需要 Node.js ≥ 22。

```bash
npm install
npm run dev      # 开发模式（Vite 热更新 + Electron）
npm run build    # 编译主进程与渲染层
npm run dist     # 打包 Windows 安装包（输出到 release/）
```

首次启动会进入引导页，填入邮箱与服务商授权码即可。**建议使用一个专用邮箱**：收件箱会成为顶部「任务」列表，邮箱中所有以 `Todo-` 开头的文件夹都会成为列表区里的自建列表。因此收件箱里的每一封邮件都会被当成一条待办——用专用邮箱就不会被日常邮件干扰。

### 支持的邮箱

| 服务商 | 凭证 | 说明 |
|---|---|---|
| 163 / 126 | 客户端授权码 | 需在「设置 → IMAP/SMTP 服务」中开启 |
| iCloud | App 专用密码 | 在 appleid.apple.com 生成 |
| 其它 / 自建域名 | IMAP 密码 | 手工填写服务器与端口 |

> 微软个人邮箱已关闭密码登录 IMAP，需要 OAuth2，当前版本未支持。

## 已知限制

- 单账号；不支持子任务、重复任务、共享列表
- 用手机邮件客户端点开一封任务邮件，等价于「把它标为完成」——这是数据模型本身决定的
- 部分邮箱（如 163）不支持文件夹层级、`MOVE`、`IDLE`，应用据此把同步降级为轮询
